## Cursor Cloud specific instructions

This repository is a **document-only resume repository** — it contains no application code, no build system, no dependencies, and no services to run.

### Repository contents

- `Resume.docx` — Microsoft Word 2007+ resume document
- `Resume.pdf` — PDF version of the resume (1 page)

### Development notes

- There are no lint checks, automated tests, build steps, or runnable applications.
- No package managers, Dockerfiles, or configuration files exist.
- Changes to this repo involve editing the `.docx` file and exporting to PDF.
- The `.DS_Store` file is a macOS artifact and can be ignored.
